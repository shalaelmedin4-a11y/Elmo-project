# POV: Ein Tag als Chad

`pov_ein_tag_als_chad.mp4`: TikTok-Format 1080×1920, 24 fps, H.264 + AAC, 50 s. Komplett per Code erzeugt, ohne Video-KI.

| Datei | Inhalt |
|---|---|
| `paper.py` | Papier-Cutout-Zeichenkit: dicke schwarze Umrisse, Papierstruktur, „geschnittene“ Kanten, Schatten |
| `chars.py` | Chad (nur in Spiegelungen), die anderen Figuren, Chads POV-Hände |
| `render.py` | Intro und 8 Szenen, 12 Bilder/s (Stop-Motion), Kamerawackeln, Uhrzeit-Schild |
| `voices.py` | Stimmen mit edge-tts: Chad = Florian (Multilingual), Freund = Killian, Mama = Seraphina, Fans = Amala, Seraphina und Katja |
| `audio.py` | Selbst gebauter Lo-Fi-Hip-Hop-Beat (Kick, Snare, Hi-Hat, Keys, Bass) bei ca. 15 %, unter den Stimmen auf ca. 6 % abgesenkt; dezente Effekte |
| `sheet.py` | Kontaktbogen einzelner Sekunden zur Kontrolle |
| `previews/` | Vorschaubilder |

Neu bauen: `./build.sh`
